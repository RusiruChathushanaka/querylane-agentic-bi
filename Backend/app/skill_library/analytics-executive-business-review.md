## Workflow
Capture audience, decision, sources, reporting period and metric definitions. Prefer the latest complete period within actual source coverage; state its gap to today. Use published metric versions when applicable. Request Advanced Analysis for a durable multi-part Business or Technical report; ordinary chat can provide a smaller summary with its saved evidence.

Prioritize revenue/orders/AOV, category or regional contributions, merchandise margin and refunds where available. Compare equivalent periods and explain denominators. Reconcile segment contributions to the total before highlighting drivers. Separate observed associations from explanations that need additional evidence.

## Report structure
Lead with the decision and verified findings. Follow with trends, segment comparisons, data-quality limitations and recommendations. Link every numerical claim to saved calculations or result artifacts. Put SQL, independent source timestamps, assumptions, units, metric and skill versions in evidence. Recommendations are proposed actions, not established findings.

Forecast only when the decision needs future values and controlled validation supports them. Label predictions, conditional scenarios and management adjustments separately. Reuse a saved Forecast Plan only through its explicit version; changes to data require new analytical work. Report downloads must match the immutable published report.

## Example
Create a Business-style quarterly retail review explaining revenue change, category contributions, returns and practical next steps. Include a forecast only if it helps the stated decision.
