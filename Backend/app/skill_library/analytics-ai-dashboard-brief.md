## Workflow
Clarify the audience, business objective, date range, sources and definitions. Recommend the smallest useful set of distinct cards: usually a headline KPI, chronological trend, segment comparison and target/returns detail. Use the AI Dashboard Builder for an actual proposal; a skill itself does not add creation tools to chat.

Match each card to a concrete analytical question and published metric revision when available. Plan within the builder's existing card and new-analysis budgets. Suitable saved evidence must match metric version, filters, grain, units, source profile and completeness; a similar title is insufficient. Retain actual cutoffs and source timestamps on reused cards.

## Presentation and review
Choose KPI for a headline value, line/area for ordered time, bars for categories and a table when exact values or mixed units matter. Use restrained highlights; higher refunds or costs are not inherently favorable. Avoid duplicate cards from one artifact. Compare proposed additions, edits, retained cards and explicit removals with the current dashboard.

New forecasting belongs in Advanced Analysis or Forecast Plans; the builder can reuse compatible saved predictions. Publication is a separate visitor review action. Opening, sharing or exporting a saved dashboard does not refresh its data.

## Example
Propose a four-card retail leadership dashboard for the latest complete quarter, reusing matching saved evidence and stating which questions need new analysis.
