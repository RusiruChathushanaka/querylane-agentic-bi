# Public report claims come from controlled calculations and validated predictions

Status: Accepted — 2026-10-17

Models decide what to investigate and explain validated evidence; they do not execute generated Python, invent numerical values, or authorize new data access. Report claims carry stable evidence IDs. Numerical tools use saved complete results, chronological backtests, explicit domains and bounded execution. A candidate must improve its baseline; unsupported predictions are withheld or retain a defensible baseline with limitations. Learned scenarios are conditional predictive associations, not intervention effects.

The writer and semantic reviewer have distinct roles. The renderer inserts verified claim values; bounded narrative failure produces labeled evidence summaries. A model review is an additional check, not a replacement for independent numerical fixtures or SQL permissions.

Google Search is a separate requester-only, in-memory research panel. Its grounded responses, source attribution and required suggestions never enter shared report storage, writer context or exports. This conservative boundary follows the requester-display/storage constraints in the current Google Cloud service terms and avoids presenting external research as verified database evidence.
