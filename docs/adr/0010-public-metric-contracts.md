# ADR 0010: Public, executable business metric contracts

Accepted 18 October 2026 for local implementation; deployment is separate.

Shared Markdown skills are guidance, not deterministic definitions. Introduce a public versioned catalog whose expressions compile through application-owned source/grain mappings. Everyone may publish after structural validation; the product must not imply verified authorship or organizational certification.

Published dependency revisions and analysis snapshots remain immutable. Ad hoc analysis is explicit and unlabelled as catalog-certified. Forecast feature preparation must preserve canonical target values. This adds compiler and lineage maintenance, while preventing shared text instructions from changing execution permissions or historical calculations.
