# TimesFM implementation verification — 17 October 2026

[Managed TimesFM comparison](../timesfm.md) is implemented locally and **disabled by default**. No deployment, GitHub push, IAM change, analytical source query/upload, skill seed, history reset or hosted feature enablement was performed. The larger dataset and existing Cloud Run configuration were untouched. [Machine-readable evidence](timesfm-local.json) records source hashes and boundaries.

- **385 backend tests passed, one existing emulator-dependent skip**; 45 new TimesFM cases cover eligibility, complete 45-month/1,369-day shapes, fold isolation, promotion/ties, conditional scenarios, parameterized SQL, failure statuses, invalid domains, fenced reservations, ambiguous submission, completed-job recovery, late cancellation, checkpointed forecast/scenario publication and saved-format reconciliation.
- **47 frontend tests passed**; Ruff, frontend lint, TypeScript and isolated production build passed. Existing report, skills, SQL/voice, dashboard, retention, export and numerical regressions remain in the full suite. The existing Starlette/httpx warning remains.
- Local Chromium exercised the actual result component with an explicitly labeled fixture, native disclosure keyboard activation, model/Preview labels, semantic caption/headers, 320px/390px layouts, dark mode and reduced motion. No page overflow or uncaught errors was recorded; axe reported **zero violations**, 51 passes and no incomplete checks on the tested disclosure page. Next.js runtime tools returned no compilation/config/session issues. This is UI evidence, not a live model report.
- [Operator compatibility](timesfm-operator-compatibility.json) passed **four real managed inference jobs** in `asia-southeast1`: three-fold monthly batch, final monthly prediction, three-fold daily-driver batch and final baseline/alternative scenario batch. Inputs were synthetic inline parameters; no analytical tables were accessed. Fixed queries, context handling, output dates/status/shape and billing metadata worked. This does not establish real-world predictive accuracy or worker permissions.
- [Worker compatibility](timesfm-worker-compatibility.json) remains **unverified**: ADC was absent and the existing CLI identity lacks `iam.serviceAccounts.getAccessToken` for that worker. No grant was added. Both enablement flags remain false. Actual worker access must be tested during an authorized release before enabling the feature.

A test fixture initially omitted the export document's required `claims` field; correcting that fixture produced the final full-suite pass. Earlier intermediate suite counts are superseded by the final result above. Managed-probe source values are intentionally not represented as the larger retail dataset's business results. Full physical audio, cross-browser/screen-reader coverage, production task crash injection and a hosted TimesFM report release are outside this implementation check.
